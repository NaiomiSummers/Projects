Launcher

Launcher provides the suite entry page, terms display and navigation to available modules. The current interface distinguishes the available Tables editor from the planned Papers and Present modules. Tables

Tables opens user-selected OpenDocument Spreadsheet (.ods), Excel workbook (.xlsx) and UTF-8 comma-separated value (.csv) files into a working copy in browser memory. The current editor supports selected cell editing, formatting, worksheets and calculations. It does not support every feature of these formats. Legacy and macro-enabled workbook formats are not supported inputs.

The default download is an .ods copy. You may also export .xlsx or a .csv of the active worksheet. CSV contains values from that worksheet and does not preserve the workbook's other sheets, formatting or formula definitions. Copy and paste use the browser or operating-system clipboard; copied cell values can be available outside the editor.

Originals, downloads and sharing

The current editor reads a working copy and requests downloads of new copies; it does not automatically write edits back to the original file. Keep the original and a separate backup. Export before leaving the editor, confirm that the browser actually saved the download, and reopen it in the intended application before replacing an original or relying on it. A download request or an absence of pending edits is not proof that every workbook feature was preserved.

The app does not add file-content encryption to its exported copies. Choose storage locations and recipients appropriate to the information in the files. Downloads, clipboard contents and copies placed in shared or synchronized folders can be accessible outside FileBirch. Review names, sheets, formulas, comments or embedded material retained by the selected export path before sharing, and do not treat conversion as redaction.
