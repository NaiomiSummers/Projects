Your data & backups

Where records live
Entries, drafts and settings are encrypted before being stored locally in the browser or installed app. Clearing site data, removing the app, or losing the device can remove access.
Prevent data loss
In Settings → Encrypted backup → Create a backup, create and save the password-protected .dat file. Keep the password used to create it. Report PDFs contain readable information.
Restore your records
Back up the current local journal first. Use Settings → Restore a backup, select the .dat file and enter its original password. Preview the contents before replacing entries, contacts and settings. The destination uses its current vault password.

How to use Dayleaf

  1. Create and unlock the vault at the app’s HTTPS address.
  2. Use Today for the daily check-in. Drafts save as you go. Review earlier entries in History and use Weekly and Workbook when relevant.
  3. Use Lock now when stepping away. If installing on your phone, open the Home Screen copy online once and check its offline status in Settings.
  4. Restore from an encrypted backup if moving records into an installation that starts with an empty vault.

Try it with sample data

Start a fictional daily entry, leave it as a draft, and return to the same date to see how draft saving works. Use a separate synthetic vault when practicing backup restore.

If something goes wrong

If an installed copy opens empty, check the original Safari or browser copy before deleting anything. Export its encrypted backup and restore it in the destination.
